# ODMR IO Module

The ODMR IO module provides classes for loading and saving ODMR data from various file formats.

## BaseLoader

The `BaseLoader` is an abstract base class for all ODMR data loaders.

      show_root_heading: true

## MatlabLoader

The `MatlabLoader` loads ODMR data from MATLAB (.mat) files.
