# Tutorials

Welcome to the QDMpy tutorials. These tutorials are designed to help you get started with QDMpy and learn how to use its various features for analyzing Optically Detected Magnetic Resonance (ODMR) data from Nitrogen-Vacancy (NV) centers in diamond.

## Available Tutorials

- **[Basic Tutorial](basic.md)**: Learn the fundamentals of loading, processing, and visualizing ODMR data with QDMpy
- **[ODMR Processors](processors.md)**: Explore the various signal processing techniques for ODMR data
- **[Model Fitting](fitting.md)**: Learn how to fit ODMR spectra and use the ConstraintManager
- **[Custom Models](models.md)**: Create and use custom spectral models for ODMR data analysis

## Jupyter Notebooks

All tutorials are available as Jupyter notebooks, allowing you to follow along and execute the code interactively. The notebooks are available in the project repository:

- `tutorial.ipynb`: Basic tutorial
- `processor_tutorial.ipynb`: ODMR processors tutorial
- `tutorial_fitting.ipynb`: Model fitting tutorial
- `tutorial_models.ipynb`: Custom models tutorial

You can run these notebooks locally after [installing QDMpy](../installation.md) by cloning the repository and launching Jupyter:

```bash
git clone https://github.com/mikevolk/QDMpy.git
cd QDMpy
jupyter notebook
```
